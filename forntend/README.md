 AI Screening App Frontend Setup

## Clone the Repository

To get started, clone the repository to your local machine:

```bash
git clone git@github.com:Abhijit1102/ai_screening_app.git
```

Navigate to the frontend directory:

```bash
cd ai_screening_app/frontend
```
Install Dependencies
Run the following command to install the required dependencies using npm:

```bash
npm install
```

Run the Frontend
After installing the dependencies, start the frontend development server:

```bash
npm run dev
```
This will start the frontend server, and it should now be running on http://localhost:3000 (or the port defined in your project).
